# 001 — Basic Operations

## Objective

Develop a C program that reads two integer values from the user and displays the result of the following operations:

- Addition
- Subtraction
- Multiplication
- Integer division
- Remainder of the division

## Requirements

- Use `printf` and `scanf` for user interaction.
- Store the input values using appropriate integer types.
- Prevent division by zero.
- Display the results in a clear and organized format.
- Keep the program structure simple and readable.

## Test Cases

The program should be tested with at least the following cases:

- Two positive integers
- Two negative integers
- One positive and one negative integer
- Zero as the first value
- Zero as the second value
- Two equal values
- A division that produces a remainder
- Division by zero

## Expected Skills

This exercise is intended to reinforce:

- Variable declaration
- Integer data types
- Arithmetic operators
- User input and output
- Conditional statements
- Basic error handling
